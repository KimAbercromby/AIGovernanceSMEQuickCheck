# AI Quick Check

An on-screen version of the AI Request and Quick Check (Gate 1) from the AI Governance Kit for small accountancy firms.

Staff describe the AI tool and how they want to use it, check the not-permitted list, answer five supplier checks and seven quick-check questions, and see the result straight away:

- **Likely low risk:** the AI Lead can confirm it and add it to the register.
- **Talk to the AI Lead:** some answers are unsure and need a short conversation.
- **Risk check needed:** a closer look using the AI Risk Check (SME-04), with the checks likely to apply.
- **Not permitted:** the use is on the not-permitted list.

The result can be copied into an email to the AI Lead, or downloaded as a request summary. The register line downloads as a CSV with the same columns, in the same order, as the Register sheet of the AI Register workbook (SME-06).

The tool does not approve anything, and nothing typed into it is stored or sent anywhere. It is a single self-contained page (`index.html`), hosted on GitHub Pages.

Adapted from the AI Governance Playbook and Toolkit by Kim Abercromby.
